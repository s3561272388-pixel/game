# 01 · 美术与音频资源清单（背包大乱斗 · 2D 俯视 / 纯 UI）

> 适用项目：*背包大乱斗（Backpack Brawl 类）*
> 技术栈：Vite + TypeScript + React（UI） + Canvas（战斗表现）
> 风格目标：**像素风** 或 **干净扁平矢量风**（二选一，成本对比见第 7 章）
> 本文目标：让独立开发者**今天就能下单 / 下载 / 出占位图**，不被美术阻塞。
>
> 阅读顺序建议：第 5 章（占位图）→ 第 6 章（MVP 最小集合）→ 第 2/7 章（采购）→ 第 1 章（规格核对）→ 第 4 章（合规登记）。

## 0. 结论速览（TL;DR）

| 决策点 | 建议 | 理由 |
| --- | --- | --- |
| 风格 | **先像素风**（16/32 基准） | 免费资源最多、AI 一致性最好、占位图最容易被接受、整数倍缩放无锯齿 |
| 物品图标 | 先用 **game-icons.net + Kenney** 组合，后期替换自绘 | CC BY / CC0，数量足够（数千枚），SVG 可重上色 |
| 音效 | **jsfxr / ChipTone 程序生成 + Freesound 兜底** | 生成即 CC0/自有，零授权风险，反馈迭代最快 |
| 字体 | 中文 **思源黑体 / 霞鹜文楷（OFL）**，英文像素字 **查 Kenney 字体包（CC0）** | OFL 允许嵌入游戏与商用，禁止单独售卖字体文件 |
| 图集 | **free-tex-packer**（开源）或 **TexturePacker**（付费） | 输出 TexturePacker JSON Hash，前端 PIXI/自研 loader 都能吃 |
| 合规 | 建 `ATTRIBUTIONS.md` + `assets/LICENSES.csv`，**下载即登记** | 避免三个月后无法追溯来源（最常见的翻车点） |
| 预算 | 混合方案 ≈ ¥600–2500，工期 6–10 天可玩 | 详见第 7 章 |

## 1. 资源需求总表

### 1.1 规格通则

| 项目 | 约定 |
| --- | --- |
| 像素风基准网格 | 图标 **32×32**，UI 元素 8 的倍数；导出 **@1x** 与 **@2x**（64×64）两份，或只出 @1x 由运行时 `image-rendering: pixelated` 放大 |
| 整数倍缩放 | 像素资源**只允许 ×1 / ×2 / ×3 / ×4** 缩放，禁止 ×1.5、×2.37；CSS 侧统一 `image-rendering: pixelated`，Canvas 侧 `ctx.imageSmoothingEnabled = false` |
| 扁平矢量风基准网格 | 图标 **64×64**（描边 4px @2x），导出 @1x(64) / @2x(128)，禁止像素化渲染，需要 `imageSmoothingEnabled = true` |
| 通用交付 | 单图 **PNG-32（带 alpha）**；页面级大图/背景可用 **WebP（有损 q80）**；所有会动的元素进 **图集 atlas + JSON** |
| 九宫格 | 所有面板/按钮/输入框必须提供 9-slice，交付原始四边切片信息（见 `assets/manifest.json` 的 `slices` 字段） |
| 色彩空间 | sRGB，不带 ICC profile；不要预乘 alpha 混乱（统一 straight alpha） |
| 命名 | 全小写 + 下划线，禁止空格/中文/大写；见 §1.11 |
| 文件体积预算 | 首屏关键路径资源 ≤ 1.5 MB（gzip 前）；总资源 ≤ 12 MB |

### 1.11 命名规范（强制）

```
<类别>_<子类>_<名称>_<变体/稀有度>_<序号>.png
```

| 规则 | 正确 | 错误 |
| --- | --- | --- |
| 全小写 + 下划线 | `item_wpn_iron_sword_c.png` | `IronSword.PNG` / `物品_铁剑.png` |
| 序号补零两位 | `sfx_hit_crit_01.ogg` | `sfx_hit_crit_1.ogg` |
| 图集帧不带零填充歧义 | `fx_hit_slash_a_01.png` | `fx_hit_slash_a1.png` |
| 目录结构 | `assets/items/` `assets/ui/` `assets/fx/` `assets/audio/sfx/` `assets/audio/bgm/` `assets/fonts/` `assets/atlas/` | 全平铺 |
| 禁止字符 | `[a-z0-9_]` 与 `-` | 空格、括号、`#`、`&`、中文 |

## 3. AI 生成资源

### 3.1 可行性结论

| 用途 | 可行性 | 说明 |
| --- | --- | --- |
| 物品图标（像素风） | ✅ 高 | 32×32/64×64 单物件最适合，**必须要人工过一遍** |
| 物品图标（扁平矢量风） | ⚠️ 中 | 出现渐变/阴影不统一，描边粗细难控 |
| UI 九宫格 | ❌ 低 | 九宫格要求严格对称与可切片，AI 几乎做不出可用切片，**不要用 AI 做** |
| 背景纹理 | ✅ 高 | 平铺纹理、氛围底图效果好，注意接缝 |
| 特效序列帧 | ❌ 低 | 帧间一致性极差，**建议手绘或程序化生成** |
| 音效 | ⚠️ 中 | 可用生成式音频工具试验，但可循环 BGM 质量不稳定 |

### 3.2 五个主要坑

1. **一致性**：同一批 60 个图标若分批生成，笔触/比例/配色会漂移。对策：**锁定同一模型 + 同一 seed + 同一提示词骨架**，一次只换「物品名」一个变量；并固定调色板（把 HEX 写进提示词）。
2. **透明通道**：多数图像模型输出**不带 alpha**（白底或棋盘格假透明）。对策：不要指望模型出透明底，改为「**纯色高对比背景（如 #00FF00）→ 抠图**」，或直接生成在图集底板色上再用色键去除。
3. **被裁切 / 出框**：物件贴边被切。对策：提示词加 `centered, full object visible, generous margin, no crop`，并在放大到目标尺寸后**统一留 2–3px 内边距**。
4. **比例与像素网格**：生成图往往不是 32 的整数倍，直接缩小会产生半像素模糊。对策：先放大到 512，再做**最近邻（Nearest）降采样到 32/64**，然后手工修正关键像素。
5. **法务风险**：
   - 训练数据来源与模型商用条款**必须自行核对**（同款模型不同版本条款可能由「禁止商用」变为「允许」，反之亦然）。
   - **不要**用「模仿某在世画师风格」的提示词，也不要生成受保护 IP 形象（宝可梦、马里奥等）。
   - **不要**直接用 AI 生成的「疑似某商业素材包风格」的图标，存在风格侵权争议。
   - Steam / Google Play / App Store 要求**申报 AI 生成内容**；未申报可能被下架。itch.io 也要求标注。
   - 保留**生成记录**（模型、版本、提示词、日期、seed）到 `docs/ai-generation-log.md`，作为原创性证明。

### 3.3 推荐流水线

```
① 定规范      调色板 + 线宽 + 画布尺寸 + 光源方向（写进 docs/style-guide.md）
      ↓
② 批量出图    同一模型同 seed，脚本批量替换物品名（白底/纯色底，512×512）
      ↓
③ 抠图        Krita/GIMP 色键 → 修边（去杂色、补缺口）
      ↓
④ 统一化     统一描边（外侧 1px 深色描边或统一 2px 扁平描边）
              统一光源（左上 45° 高光 + 右下阴影）
              统一色阶（映射到项目调色板，最多 16 色）
      ↓
⑤ 网格对齐    最近邻缩放至 64 → 内容居中 → 保留 2px 内边距 → 导出 @1x/@2x
      ↓
⑥ 命名入夹    assets/items/item_wpn_iron_sword_c.png
      ↓
⑦ 图集打包    free-tex-packer → atlas/items.json + atlas/items.png
      ↓
```

### 4.3 自动化校验脚本（建议放进 CI）

```ts
// scripts/check-licenses.ts —— 构建前跑一次，任何一行不合规就让 CI 失败
import fs from 'node:fs';
const rows = fs.readFileSync('assets/LICENSES.csv', 'utf8').trim().split('\n');
const [head, ...body] = rows;
const cols = head.split(',');
const idx = (n: string) => cols.indexOf(n);

const BLOCK_LICENSES = [/NC/i, /SA/i, /GPL/i, /unknown/i];
const needAttr = new Set<string>();
const problems: string[] = [];

for (const line of body) {
  const c = line.split(',');
  const file = c[idx('file')], lic = c[idx('license')];
  if (c[idx('commercial_ok')].trim() !== 'true') problems.push(`商用未确认: ${file} (${lic})`);
  if (BLOCK_LICENSES.some(r => r.test(lic))) problems.push(`禁用许可: ${file} (${lic})`);
  if (c[idx('attribution_required')].trim() === 'true') needAttr.add(file);
  if (!fs.existsSync(file)) problems.push(`文件不存在（占位图替换后未更新?）: ${file}`);
}

const attr = fs.readFileSync('ATTRIBUTIONS.md', 'utf8');
for (const f of needAttr) {
  const base = f.split('/').pop()!.replace(/\.(png|webp|ogg|wav|svg|woff2|ttf)$/, '');
  if (!attr.includes(base.split('_').slice(0, 2).join('_'))) problems.push(`缺署名: ${f}`);
}
if (problems.length) { console.error(problems.join('\n')); process.exit(1); }
console.log(`licenses ok: ${body.length} files`);
```

### 4.4 三类最常见的侵权坑（必须避开）

| 坑 | 典型场景 | 后果 | 正确做法 |
| --- | --- | --- | --- |
| **① 买断的付费素材包被再分发** | 把买来的 UI 包原图放进公开 GitHub 仓库 / 打包进 npm 包 / 分享给外包画师做参考模板 | 违反 EULA，多数平台可下架并索赔 | 付费素材**只提交构建产物到私有仓库**；公开仓库用 `.gitignore` 排除原始素材；把 EULA 原文存到 `docs/licenses/` |
| **② CC-BY 漏署名** | 从 OGA / Freesound 拿了 CC-BY 音效，忘了写 `ATTRIBUTIONS.md` | 授权自动失效 = 侵权；被作者发现要求下架 | 下载当刻就在 `LICENSES.csv` 加行并同步 `ATTRIBUTIONS.md`；CI 校验（§4.3） |
| **③ AI 素材被平台标记** | 商店页未申报 AI 生成内容；或使用了明显模仿某画师/某 IP 的产出 | 商店下架、账号处罚、退款风波 | 保留生成日志；按平台要求申报；避免「in the style of <在世画师>」与受保护 IP 提示词 |

**另外三条容易忽略的**：

- **字体嵌入**：把商用字体的 TTF 直接塞进 `public/` 供浏览器加载，等于分发字体文件，多数商业字体 EULA 禁止 → 只用 OFL/Apache 字体，或购买 Web 字体授权。
- **音乐「免费下载」≠ 可商用**：YouTube 素材库歌曲可能仅限该平台使用。
- **模型/模组授权**：若使用社区做的素材转换器或 AI 模型，其权重许可可能带非商用条款，需单独核对。

## 5. 占位图策略（关键）

### 5.1 目标

> **美术未到位时，代码零阻塞**；美术到位后，**只替换文件、不改一行代码**。

### 5.2 三级占位方案

| 级别 | 方案 | 适用 | 实现成本 | 观感 |
| --- | --- | --- | --- | --- |
| L1 | **纯色块 + 文字标签** | 物品图标、槽位、按钮 | 5 分钟 | 丑但信息清楚 |
| L2 | **程序化生成几何图标（Canvas / SVG，64×64）** | 物品图标、Buff 图标、特效帧 | 1–2 小时 | 可用，能直接测 UI 布局 |
| L3 | **图标字体当临时图标**（Lucide / Tabler / Material Symbols） | 通用 UI 按钮 | 30 分钟 | 相当体面，甚至可留作正式 UI |

### 5.3 L2：Canvas 程序化图标生成器（可直接粘）

```ts
// scripts/gen-placeholders.ts —— pnpm tsx scripts/gen-placeholders.ts
import { createCanvas } from '@napi-rs/canvas';
import fs from 'node:fs/promises';

type Spec = { id: string; shape: 'circle' | 'rect' | 'tri' | 'diamond'; color: string; label: string };
const PALETTE = ['#e05a5a', '#e0a15a', '#e0d45a', '#6fbf5a', '#5aa8e0', '#8a5ae0', '#e05aa8', '#9aa5b1'];

/** 稳定伪随机：同一 id 永远得到同一套几何，便于人工核对 */
function hash(s: string) { let h = 2166136261; for (const c of s) { h ^= c.charCodeAt(0); h = Math.imul(h, 16777619); } return h >>> 0; }

function draw(spec: Spec, size = 64) {
  const c = createCanvas(size, size); const g = c.getContext('2d');
  const h = hash(spec.id); const rnd = (n: number) => ((h >> (n * 3)) % 1000) / 1000;
  // 底：棋盘格表示透明？不 —— 透明背景，方便验证 alpha 管线
  g.clearRect(0, 0, size, size);
  g.fillStyle = spec.color; g.strokeStyle = '#1f2933'; g.lineWidth = 4; g.lineJoin = 'round';
  const cx = size / 2, cy = size / 2, r = size * 0.34;
  switch (spec.shape) {
    case 'circle': g.beginPath(); g.arc(cx, cy, r, 0, Math.PI * 2); g.fill(); g.stroke(); break;
    case 'rect':   g.beginPath(); g.roundRect(cx - r, cy - r, r * 2, r * 2, 8); g.fill(); g.stroke(); break;
    case 'tri':    g.beginPath(); g.moveTo(cx, cy - r); g.lineTo(cx + r, cy + r); g.lineTo(cx - r, cy + r); g.closePath(); g.fill(); g.stroke(); break;
    case 'diamond':g.beginPath(); g.moveTo(cx, cy - r); g.lineTo(cx + r, cy); g.lineTo(cx, cy + r); g.lineTo(cx - r, cy); g.closePath(); g.fill(); g.stroke(); break;
  }
  // 统一 45° 左上光源：一条高光斜线
  g.strokeStyle = 'rgba(255,255,255,.55)'; g.lineWidth = 3;
  g.beginPath(); g.moveTo(cx - r * 0.6, cy - r * 0.2); g.lineTo(cx - r * 0.1, cy - r * 0.7); g.stroke();
  // 文字标签（只有占位图有，替换正式图后自然消失）
  g.fillStyle = '#ffffff'; g.strokeStyle = '#000000'; g.lineWidth = 3;
  g.font = 'bold 16px sans-serif'; g.textAlign = 'center'; g.textBaseline = 'middle';
  const tag = spec.label.slice(0, 3).toUpperCase();
  g.strokeText(tag, cx, size - 12); g.fillText(tag, cx, size - 12);
  return c.toBuffer('image/png');
}

const ids = JSON.parse(await fs.readFile('assets/manifest.json', 'utf8'));
const out = 'assets/items/placeholder';
await fs.mkdir(out, { recursive: true });
for (const a of ids.assets.filter((x: any) => x.placeholder && x.type !== 'audio')) {
  const h = hash(a.id);
  await fs.writeFile(`${out}/${a.path.split('/').pop()}`, draw({
    id: a.id, label: a.id.replace(/^item_/, ''),
    shape: (['circle', 'rect', 'tri', 'diamond'] as const)[h % 4],
    color: PALETTE[h % PALETTE.length],
  }));
  console.log('placeholder ->', a.path);
}
```

**占位图与正式图同尺寸、同格式、同命名、同路径**，只是内容不同 → 替换时 `cp` 覆盖即可。

### 5.5 零改动替换的三条硬规矩

1. **路径即契约**：`manifest.json` 里的 `path` 是唯一真相，渲染层只认 `id` → `path`。占位图与正式图**必须写在同一路径**（正式图到位后直接覆盖文件）。
2. **尺寸即契约**：占位图与正式图的 `size` 必须一致（像素风 64×64 @2x）。否则 UI 布局会在替换后跳动。
3. **切图信息即契约**：九宫格占位与正式图的 `slices` 必须一致；特效占位帧数可少，但**帧尺寸必须一致**。

### 5.7 加载器伪代码（占位图透明切换）

```ts
export async function loadAsset(id: string) {
  const a = manifest.assets.find(x => x.id === id);
  if (!a) throw new Error(`asset not found: ${id}`);
  const img = new Image();
  img.src = a.atlas ? manifest.atlases[a.atlas].image : a.path; // 占位图与正式图共用同一字段
  await img.decode();
  return { img, size: a.size, pivot: a.pivot, frame: a.frame, slices: a.slices, placeholder: a.placeholder };
}
```
