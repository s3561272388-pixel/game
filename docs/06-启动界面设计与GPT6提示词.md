# 06 · 启动界面（共鸣终端）设计与 GPT-6 提示词

**目标**：为《共鸣行囊》做一个契合鸣潮 HUD 语汇、且与游戏内界面**同源**的启动界面。
**产出**：本文档 = 设计规范 + 素材清单 + 可直接复制的 **P9 提示词**。
**tokens**：`data/ui-theme.json`（唯一来源，组件里禁止写死色值/字号/时长）。

**可复用的四条规则**
1. **编号式标题**：`01 / SUPPLY`、`02 / BACKPACK`、`03 / RESONATOR`——用大写英文 + 等宽数字做分区标识。
2. **左右夹击的 HUD 数据**：左上角是"叙事性文案"（SOLARIS-3 / 行囊就绪），右上角是"状态读数"（进度/命值/货币，数字用等宽大字）。
3. **深色卡片 + 1px 青蓝描边 + 直角切角**，hover 时描边变亮并加内发光，绝不使用圆角。
4. **底部常驻操作提示**：按键提示用 `键名 + 动词` 的等宽小字，最重要的动作做成金色切角主按钮。

### 0.2 色板（从截图采样，已整理进 `data/ui-theme.json`）

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面底色 | `#080B10` | 接近纯黑的墨蓝，不是 #000 |
| 面板底 | `#12171F` | 比底色亮 1 档，靠 1px 描边区分而不是阴影 |
| 主色（青蓝） | `#6FE3F2` | 所有"信息/可交互/科技感"都用它 |
| 强调色（金铜） | `#E3C08A` | 只给**主行动**（进入试炼）与"传世"稀有度，稀缺才显贵 |
| 主文字 | `#E9EDF2` | |

> **关键克制**：截图里金色只出现在"进入共鸣试炼"这一个按钮上。启动界面的金色也必须只留给**主行动**，
> 否则整屏都在喊，等于没人在喊。

### 0.3 装饰语言（鸣潮的辨识度就靠这些）

- **切角几何**：所有容器/按钮用 `clip-path` 切掉对角，不用 `border-radius`
- **HUD 四角括号**：面板四角用 1px 直角短线"夹住"，`⌐ ¬ ∟ ⌐` 那种
- **菱形指示器**：当前选中项左侧一个 6×6 旋转 45° 的青蓝菱形
- **细扫描线与噪点**：全局叠加层，透明度 ≤ 0.06，是"终端感"的来源
- **等宽数字**：所有数值用 JetBrains Mono，读数对齐才有仪表盘感
- **极大字距的英文副标题**：`RESONANCE BACKPACK BRAWL`，`letter-spacing: 0.34em`

## 1. 启动界面的定位：它不是"主菜单"，是「共鸣终端」

命名与文案是风格的一半。左侧标题区写成终端自检的口气，而不是"开始游戏 / 设置 / 退出"。

**概念**：玩家打开页面，看到的是一台正在启动的**声骸共鸣终端**。终端完成自检后，把"行囊"交给玩家。

- 界面代号：**共鸣终端 / RESONANCE TERMINAL**
- 面包屑：`SOLARIS-3 / TERMINAL`
- 主标题：`共鸣行囊`（68px / 900 字重 / `letter-spacing .16em`）
- 英文副标题：`RESONANCE BACKPACK BRAWL`
- 一句话定位：`在有限的格子里，构建你的共鸣链路。`
- 底栏：`素材来源与授权` · `本作为个人学习作品，与库洛游戏无关` ← **这条必须有**

## 3. 图层结构与视觉特效

| 层 | 内容 | 视差位移 | 动效 |
|---|---|---|---|
| **L0** 底色与网格 | 径向渐变（青蓝光晕，中心偏右上）+ 48px 网格线（`rgba(127,231,240,.05)`） | ±8px | 网格极缓慢平移（120s 循环） |
| **L1** 频谱环 | 3 圈同心圆 + 64 根辐射短线，`stroke: cyanDim`，opacity .18 | ∓6px | 自转 60s/圈；短线长度随"呼吸"波动 |
| **L2** 角色立绘 | PNG 透明，底部用遮罩渐隐融入背景 | ±14px | 呼吸 scale 1↔1.005（4s）；入场时从右滑入 + 一次横向扫描光 |
| **L3** 内容区 | 标题 / 菜单 / 主按钮 | 0 | 逐字与逐条入场；hover 微位移 |
| **L4** 顶栏底栏 | logo、版本、帮助、设置、授权 | 0 | 最后淡入 |
| **L5** 全局叠加 | 扫描线（每 6s 一次，1.2s）、暗角 `radial-gradient`、噪点 PNG（opacity .04） | 0 | 循环；`prefers-reduced-motion` 时关闭 |

**粒子**：24 个 4×4 青蓝菱形，从底部缓慢上升（18–30s 走完全程），opacity 0.05–0.18，随机相位。
用 `<canvas>` 单层实现（`pointer-events: none`），或纯 CSS（≤24 个元素性能可接受）。

## 4. 状态机与动画时间轴

```
BOOT ──(2.2s / 任意键跳过)──► IDLE ⇄ NAV ──(确认)──► CONFIRM ──► 转场
                                          └─(需存档但无存档)─► DENY
```

### 4.1 BOOT 时间轴（总计 2200ms）

| 时间 | 动画 | 实现要点 |
|---|---|---|
| 0–200 | 全黑 → 从画面中线向上下展开 | `clip-path: inset(50% 0 50% 0)` → `inset(0)` |
| 200–800 | 网格与频谱环淡入，频谱环用 `stroke-dashoffset` 描画 | `stroke-dasharray` 动画 |
| 600–1000 | 角色立绘从右侧 +40px 滑入，opacity 0→.85，伴随一次横向扫描光 | 扫描光 = 一条 2px 青蓝渐变条横向掠过 |
| 800–1400 | 标题逐字浮现（每字 delay 60ms，blur 2px→0） | `@keyframes decode`，字用 `<span>` 拆开 |
| 1200–1800 | 6 个菜单项逐条从 `translateX(-12px)` 归位 | delay 100ms 递进 |
| 1800–2200 | 顶栏/底栏淡入；面板四角 HUD 括号用描边动画画出 | `stroke-dashoffset` |
| 2200 | 进入 IDLE，播放 `sfx_ui_boot` 尾音 | |

**必须可跳过**：BOOT 期间任意键/点击 → 立即跳到 IDLE 终态（不是加速播放，是直接置终态）。
老玩家和录屏者会感谢你。

### 4.2 IDLE / NAV

- 鼠标视差：`L0 ±8px`、`L1 ∓6px`、`L2 ±14px`，缓动系数 0.06（`lerp`，`requestAnimationFrame`）
- 键盘 ↑↓ 或鼠标 hover 切换选中项：
  - 菱形指示器沿垂直轴滑动（`transform: translateY`，spring 缓动）
  - 选中项文字 `translateX(6px)`，左侧出现 2px 青蓝竖条
  - 该项的 `hint` 文案在右侧淡入
  - 顶栏下方一条 1px 扫描线从左到右跑一次（200ms）
- 音效：hover 播 `sfx_ui_hover`

### 4.3 CONFIRM

按钮从左到右被金色填充（180ms）→ 全屏白闪 60ms（opacity .12）→ 界面整体 `clip-path` 横向收拢 → 进入下一场景。

### 4.4 DENY（不可用项）

`继续试炼` 在无存档时：文字降到 `--text-dim`，右侧显示 `无存档`，点击时整个按钮横向抖动 3 次（每次 60ms，位移 ±4px）+ 播 `sfx_ui_deny`。

## 5. 交互规范

### 5.1 键盘与焦点

| 键 | 行为 |
|---|---|
| `↑` `↓` | 上下移动选择（不循环，到头停住） |
| `Enter` / `Space` | 确认当前项 |
| `Esc` | 返回 / 在 IDLE 再按一次弹出"退出终端"确认 |
| `Tab` / `Shift+Tab` | 标准焦点顺序，焦点环 = `1px 青蓝 + 内发光` |
| 任意键（BOOT 中） | 跳过入场动画 |

### 5.2 六个菜单项的功能与状态

| 项 | 副标题 | 行为 | 状态条件 |
|---|---|---|---|
| 开始共鸣 | NEW RUN | 若已有存档 → 先弹二次确认「将覆盖现有试炼记录」 | 始终可用 |
| 继续试炼 | CONTINUE | 读 `localStorage` 的 `RunState`，显示 `第 N 回合 · 命值 x/5 · 存档 M 分钟前` | **仅当有合法存档**；`RunState` schema 校验失败时视为无存档 |
| 物品图鉴 | ARCHIVE | 显示 `已解锁 X / 40` | 始终可用 |
| 玩法指南 | MANUAL | 打开规则页 | 始终可用 |
| 设置 | CONFIG | 音量 / 色盲模式 / 屏幕震动 / 减少动态效果 | 始终可用 |
| 退出终端 | TERMINATE | Web 环境调 `window.close()`；失败则显示"请手动关闭标签页" | 非浏览器壳环境隐藏此项 |

> **读档必须做 schema 校验**：`localStorage` 的数据可能来自旧版本。校验失败时**不要崩溃**，
> 降级为"无存档"并把损坏数据另存到 `backpack-brawl:run:corrupt` 便于排查。

## 6. 表情包使用方案（emoji.wuwa.games）

### 6.1 这个站是什么（已核实）

- 站点：**呜哇小站 · 表情包仓鼠库**，由潮友自发建设的**鸣潮表情包仓库**，含角色图鉴 / 表情图鉴 / 无限画廊。
- 授权实情：站方写明 **「众筹免费使用」**，作品来自**愿意授权的画师与约稿人**；
  站方在「穗穗念」页面明确表达过对**恶意倒卖**的反感。
- 技术形态：以 `webp` 为主的方图表情，尺寸较小（通常百像素级），适合做**反馈件**，不适合做立绘。

### 6.2 四条红线（写进提示词，让 GPT-6 别乱来）

1. **只能用于个人非商用的学习/二创项目**；一旦涉及商业化（上架、内购、广告），**必须全部替换或删除**这些表情包。
2. **禁止再分发**：不要把表情包打包进仓库的 `public/` 里公开分发；建议放在本地 `assets/emoji/` 并确保该目录被 `.gitignore` 忽略（或仅保留你自己获授权的部分）。
3. **禁止声称原创**：署名页必须写「表情包来源：呜哇小站 · 表情包仓鼠库（emoji.wuwa.games）+ 各原作者」。
4. **鸣潮 IP 属于库洛游戏**。这层二创关系必须在署名页与启动界面底栏明示"非官方、与库洛游戏无关"。

> 需要更细的条款请自行阅读该站的**服务条款 / 隐私协议**。本文不构成法律意见；
> 若项目要商业化，最稳的做法是**不用任何 IP 相关素材**，改用 `docs/01` 里的 CC0 资源或原创/AI 生成素材。

### 6.3 五个具体用法（低成本、高回报）

| # | 场景 | 做法 | 价值 |
|---|---|---|---|
| 1 | **BOOT 加载轮播** | 入场 2.2 秒里，角色位每 400ms 换一个表情（5–6 张），替代枯燥的 loading 文字 | 把"等待"变成"演出" |
| 2 | **角色气泡** | IDLE 超过 8 秒无操作 → 头顶弹出随机表情气泡（如疑惑/催促），2.5s 后淡出；每次进入只触发一次 | 角色"活着" |
| 3 | **菜单反应** | 选中不同菜单项时角色换对应表情：开始=兴奋、图鉴=好奇、退出=不舍 | 让菜单有情绪，帧成本几乎为零 |
| 4 | **空存档** | 「继续试炼」不可用时，角色显示无奈表情 + 气泡"还没有行囊记录" | 把禁用态讲清楚而不是冷冰冰灰掉 |
| 5 | **彩蛋** | 连续点击角色立绘 5 次 → 触发专属表情 + 音效 + 一行台词 | 玩家会去告诉朋友 |

### 6.4 接入技术规范（重要，做错会很丑）

表情包是**小尺寸方图**，直接贴在深色 HUD 上会像一张贴纸糊上去。必须做融合处理：

```css
/* 表情包统一容器：只在气泡内保持原色 */
.emoji-bubble {
  width: 128px; height: 128px;         /* 气泡内用 @2x，保证不糊 */
  image-rendering: auto;               /* 非像素风，不要用 pixelated */
  filter: drop-shadow(0 0 12px rgba(111,227,242,.35));
}
/* 直接叠在画面上的（非气泡）低干扰用法 */
.emoji-ambient {
  opacity: .55;
  mix-blend-mode: screen;              /* 让白底/亮部融进深色背景 */
  filter: saturate(.78) hue-rotate(-8deg) brightness(1.05); /* 往青蓝基调拉 */
  mask-image: radial-gradient(circle, #000 62%, transparent 72%); /* 去方角 */
}
```

**硬性约束**
- 所有表情包走 `assets/emoji/manifest.json` 登记（字段同 `docs/01 §5`），代码通过 **id** 引用，禁止写裸路径
- 加载失败必须**静默降级**为文字气泡，绝不允许出现裂图
- 单张表情 ≤ 200KB；总量 ≤ 2MB；全部 `loading="lazy"` 或预加载后缓存
- 尺寸只允许 1× (64) / 2× (128)，**禁止非整数缩放**（会糊）
- **绝不用表情包当角色立绘或图标**——立绘见 `docs/01` 的渠道清单

## 8. 无障碍与性能

| 项 | 要求 |
|---|---|
| 对比度 | 关键文本 ≥ 4.5:1；`--text-mute` 仅用于非关键标签且 ≥ 3:1 |
| 键盘 | 全部功能可纯键盘完成；焦点可见且顺序符合直觉 |
| `prefers-reduced-motion` | 关闭视差/粒子/扫描线，动画时长 ×0.2，BOOT 直接置终态 |
| 色盲模式 | 金色 → 蓝色系替换；稀有度不能只靠颜色区分，必须带文字标签 |
| 屏幕震动 | 默认开，可在设置关闭；关闭后 DENY/受击不再抖动 |
| 性能 | 首屏 LCP ≤ 1.5s；入场动画期间稳定 60fps；表情包总量 ≤ 2MB |
| 首屏不阻塞 | 立绘与表情包懒加载，**不得**因为图没加载完而卡住 BOOT 动画 |

## 11. 提示词里为什么这么写（给维护者的说明）

| 提示词里的约束 | 不写会怎样 |
|---|---|
| "token 唯一来源 + 我会 grep 硬编码色值" | GPT-6 会散落几十处 `#6FE3F2`，改主题要改一天 |
| "任意键立即置终态" | 它会实现成"动画加速播放"，跳过体验很差 |
| "无存档要有原因文案" | 只会灰掉按钮，玩家不知道为什么不给点 |
| "损坏存档降级 + 备份" | 版本更新后老存档会让首屏直接白屏 |
| "表情包失败静默降级" | 网络一抖满屏裂图，而且是首屏 |
| "不许当立绘用" | 它很可能拿 128px 表情拉伸到 1400px 当角色 |
| "不许圆角/渐变按钮" | 默认 UI 库的味道会盖掉整个鸣潮气质 |
| "显式提出不一致的地方" | 它遇到没覆盖的情况会自己拍板，事后极难查 |
