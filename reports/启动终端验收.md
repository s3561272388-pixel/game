# v1.2.0 启动终端验收

验收日期：2026-09-27。范围：独立启动终端、最小游戏入口连接、Windows 桌面包装；不重新调整难度。

## 实现和范围

启动页使用提供的 `data/ui-theme.json` 原色板，在其后增加终端布局和时序参数。页面有六项菜单、独立长离立绘、频谱环、24 个粒子、视差、表情反馈、存档摘要、图鉴、指南、设置和来源弹窗。启动开场可按任意键或点击跳过。

遵从用户“不要更改游戏的其他地方”的要求，原游戏 CSS 未做全局主题改造。游戏入口仅新增 App 导出、挂载时读取存档、新建/续玩入口、单独存档时间戳和返回终端按钮。`launcher-scope-checks.json` 记录引擎、规则、角色、物品、敌人和原 CSS 与修改前的 SHA-256 一致。

## 与设计稿的实现差异

- 立绘采用独立透明角色素材；表情来自呜哇小站已记录署名的五个素材，按 64px 展示，没有把表情放大当立绘。
- 交互音效由 Web Audio 合成，未引入 OGG 音频或原作音轨。
- 小于建议区域时提示调整窗口；桌面可 F11 全屏。网页版保留六项菜单，退出时提示手动关闭浏览器标签。
- 游戏内部样式和数值保持不变；主题令牌只用于新终端。
- 未测量持续帧率或标准化 LCP，不声称达到特定 FPS/LCP。时序结果仅代表本机本次浏览器运行。

## 安装包

使用 Electron 和 NSIS 生成 Windows x64、当前用户安装器，支持安装目录选择和快捷方式。渲染进程开启沙箱、上下文隔离、Web 安全并禁用 Node；只暴露关闭窗口和全屏两个受限接口。安装包未代码签名。

已成功构建安装器并实测对应打包程序。尚未在另一台电脑执行安装、升级、卸载全流程，因此不把配置检查等同于安装生命周期验证。网页版与桌面版存档独立。
